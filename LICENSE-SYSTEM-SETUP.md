# Cutsy License System — Инструкция по настройке

## 📋 Обзор

Система лицензирования Cutsy теперь работает через **Google Sheets + Google Apps Script**:
- ✅ Один ключ = одно устройство
- ✅ Лицензия на 1 год
- ✅ Онлайн-проверка через Google API
- ✅ Защита от передачи ключей

---

## 🚀 Быстрый старт (5 шагов)

### Шаг 1: Создать Google Таблицу

1. Открой [sheets.new](https://sheets.new) или [Google Sheets](https://docs.google.com/spreadsheets)
2. Создай новую таблицу
3. Переименуй лист с "Лист1" на **`licenses`**
4. В первой строке (A1:F1) введи заголовки:

```
A1: key          | B1: activated | C1: device_id | D1: activated_at | E1: expires_at | F1: notes
```

### Шаг 2: Создать Google Apps Script

1. В таблице нажми **Расширения → Apps Script**
2. Удали весь код по умолчанию (`function myFunction() {}`)
3. Скопируй весь код из файла **`google-apps-script-backend.js`**
4. Вставь в редактор Apps Script
5. Нажми **Сохранить** (дискетка 💾)

### Шаг 3: Развернуть веб-приложение

1. Нажми **Развернуть → Новое развёртывание** (Deploy → New deployment)
2. Нажми на значок шестерёнки ⚙️ и выбери **Веб-приложение** (Web app)
3. Заполни поля:
   - **Описание**: `Cutsy License API v1`
   - **Выполнять как**: Я (ваш email)
   - **Кто имеет доступ**: **Все** (Anyone)
4. Нажми **Развернуть**
5. Подтверди разрешения (Google спросит разрешение → нажми "Дополнительно" → "Перейти" → "Разрешить")
6. Скопируй **URL веб-приложения** (пример):
   ```
   https://script.google.com/macros/s/AKfycbxXXXXXXXXXXXXXXXX/exec
   ```

### Шаг 4: Настроить Frontend

1. Открой файл **`js/license.js`** в проекте Cutsy
2. Найди строку:
   ```javascript
   static GOOGLE_SCRIPT_URL = 'https://script.google.com/macros/s/ВАШ_ID_ЗДЕСЬ/exec';
   ```
3. Замени на свой URL из шага 3:
   ```javascript
   static GOOGLE_SCRIPT_URL = 'https://script.google.com/macros/s/AKfycbxXXXXXXXXXXXXXXXX/exec';
   ```

### Шаг 5: Сгенерировать ключи

1. В редакторе Apps Script найди функцию **`generateKeys`**
2. Выбери функцию в выпадающем списке (рядом с ▶️)
3. Нажми **Выполнить** (▶️)
4. В появившемся окне введи количество ключей (например, `10`)
5. Ключи появятся в Google Таблице!

## 📊 Структура Google Таблицы

### Лист `licenses` (основной)

| Столбец | Название | Описание |
|---------|----------|----------|
| A | key | Лицензионный ключ |
| B | activated | true/false — активирован ли |
| C | device_id | Fingerprint устройства |
| D | activated_at | Дата активации |
| E | expires_at | Дата окончания |
| F | notes | Примечания |

### Лист `logs` (автосоздаётся)

Автоматически создаётся для логирования попыток активации.

CUTSY2-PRO-XXXX-XXXX-XXXX-XXXX-XXXXXXXX
```

```

## 🛠️ Управление ключами

### Ручное добавление ключа

Просто введи ключ в столбец A, остальное заполнится автоматически.

### Генерация ключей через Apps Script

```javascript
// В редакторе Apps Script выбери функцию и нажми ▶️
generateKeys(50)  // Сгенерирует 50 ключей
```

### Проверка статистики

```javascript
// В редакторе Apps Script
getStats()  // Покажет: всего, активно, просрочено, доступно
```

### Очистка просроченных

```javascript
// В редакторе Apps Script
cleanupExpired()  // Пометит просроченные лицензии
```

## 🔒 Безопасность

### Что защищает система:

- ✅ **Один ключ = одно устройство** — fingerprint привязка
- ✅ **Срок действия** — 1 год с момента активации
- ✅ **Проверка на сервере** — нельзя подделать localStorage
- ✅ **Логирование** — все попытки активации записываются

### Ограничения:

- ⚠️ Google Apps Script имеет лимиты (6 минут выполнения в день для бесплатного аккаунта)
- ⚠️ Требуется интернет для активации
- ⚠️ Google может изменить политику Apps Script

## 🐛 Отладка

### Проблема: "Сервер лицензий не настроен"

**Решение:** Не забудь заменить `ВАШ_ID_ЗДЕСЬ` на реальный URL в `js/license.js`

### Проблема: "Ключ не найден"

**Решение:** 
1. Проверь, что ключ есть в Google Таблице (столбец A)
2. Убедись, что лист называется `licenses` (а не `Лист1`)

### Проблема: "Ошибка соединения"

**Решение:**
1. Проверь URL в `GOOGLE_SCRIPT_URL`
2. Убедись, что веб-приложение развёрнуто для "Всех" (Anyone)
3. Проверь консоль браузера (F12 → Console)

### Проверка работы API

Открой в браузере URL своего Apps Script:
```
https://script.google.com/macros/s/ВАШ_ID/exec
```

Должен вернуть JSON:
```json
{
  "status": "ok",
  "message": "Ctesy License Server is running"
}
```
