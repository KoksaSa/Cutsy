# 💾 Autosave - Автосохранение

## 🎯 Назначение

Автоматическое сохранение данных приложения для:
- Восстановления после закрытия браузера
- Защиты от потери данных при сбое
- Продолжения работы с того же места

---

## ⚙️ Настройки

```javascript
Autosave.config = {
    enabled: true,              // Включено ли автосохранение
    interval: 30000,            // Интервал в мс (30 секунд)
    storageKey: 'cad_autosave_v1',
    maxAge: 7 * 24 * 60 * 60 * 1000,  // Максимальный возраст 7 дней
    showIndicator: true         // Показывать индикатор сохранения
};
```

---

## 🔧 Использование

### 1️⃣ Автоматическое сохранение

Автосохранение работает **автоматически** каждые 30 секунд.

```javascript
// При загрузке страницы
Autosave.init();  // Вызывается автоматически

// Каждые 30 секунд
Autosave.save('auto');  // Сохраняет текущее состояние
```

### 2️⃣ Ручное сохранение

**Горячие клавиши:** `Ctrl+S` (или `Ctrl+Ы` для русской раскладки)

```javascript
// В коде
manualSave();

// Или напрямую
Autosave.save('manual');
```

### 3️⃣ Восстановление данных

При загрузке страницы автоматически предлагается восстановление:

```
📥 Обнаружено сохранение

🕒 Время: 27.03.2025 14:30
📦 Деталей: 5
📑 Листов: 2

Восстановить данные? [OK] [Отмена]
```

### 4️⃣ Ручное восстановление

```javascript
// В консоли
manualRestore();

// Или напрямую
const data = Autosave.load();
if (data) {
    Autosave.restore(data);
}
```

### 5️⃣ Очистка сохранения

```javascript
// В консоли
clearAutosave();

// Или напрямую
Autosave.clear();
```

### 6️⃣ Информация о сохранении

```javascript
// В консоли
showAutosaveInfo();

// Или напрямую
const info = Autosave.getInfo();
console.log(info);

/*
{
    exists: true,
    timestamp: 1711555234567,
    age: 120000,
    ageText: "2 мин. назад",
    partsCount: 5,
    sheetsCount: 2,
    nestedCount: 8
}
*/
```

---

## 📊 Что сохраняется

| Данные | Описание |
|--------|----------|
| `parts` | Все созданные детали |
| `nestedParts` | Размещённые детали на текущем листе |
| `allSheets` | Все листы с раскладкой |
| `currentSheetIndex` | Текущий отображаемый лист |
| `showSheetView` | Показан ли вид листа |
| `markupRects` | Прямоугольники разметки |
| `sheetSize` | Размер листа |

## 🎨 Индикатор сохранения

**Расположение:** Правый нижний угол

| Статус | Цвет | Сообщение |
|--------|------|-----------|
| **Сохранено** | 🟢 Зелёный | `💾 Сохранено` |
| **Восстановлено** | 🟢 Зелёный | `✅ Восстановлено` |
| **Ошибка** | 🔴 Красный | `❌ Ошибка` |
| **Нет места** | 🟡 Жёлтый | `⚠️ Нет места` |
| **Устарело** | 🟡 Жёлтый | `⚠️ Устарело` |
| **Очищено** | 🔴 Красный | `🗑️ Очищено` |

## ⚠️ Ограничения

### localStorage квота

**Обычно:** 5-10 МБ

**При превышении:**
```
⚠️ Превышена квота localStorage

Попробуйте очистить старые сохранения или использовать меньше деталей.
```

**Решение:**
```javascript
// Очистить сохранение
clearAutosave();

// Или отключить автосохранение
Autosave.config.enabled = false;
```

### Максимальный возраст

**По умолчанию:** 7 дней

**Если старше:**
```
⚠️ Сохранение устарело (более 7 дней)
```

**Изменить:**
```javascript
Autosave.config.maxAge = 14 * 24 * 60 * 60 * 1000;  // 14 дней
```

## 💡 Советы

### 1. Отключить автосохранение

```javascript
// Временно отключить
Autosave.config.enabled = false;
Autosave.stop();

// Включить обратно
Autosave.config.enabled = true;
Autosave.start();
```

### 2. Изменить интервал

```javascript
// Сохранять каждые 10 секунд
Autosave.config.interval = 10000;
Autosave.start();  // Перезапустить таймер
```

### 3. Сохранить перед важным действием

```javascript
// Перед раскладкой
manualSave();

// Выполнить раскладку
// ...
```

### 4. Проверить наличие сохранения

```javascript
const info = Autosave.getInfo();
if (info.exists) {
    console.log('Есть сохранение:', info.ageText);
    console.log('Деталей:', info.partsCount);
}
```
