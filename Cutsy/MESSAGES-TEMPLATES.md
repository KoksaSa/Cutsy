## 🔄 Как отслеживать истечение лицензий

### Способ 1: Google Sheets (вручную)

1. Открой таблицу `users`
2. Сортируй по столбцу `E` (expires_at)
3. Ищи даты, которые через 3 дня

### Способ 2: Telegram-напоминания

1. Установи любое приложение для напоминаний
2. Добавь дату `expires_at - 3 дня` для каждого клиента
3. Получишь уведомление — отправь Шаблон 4

### Способ 3: Автоматизация (опционально)

Можно настроить Google Apps Script для автоматической отправки напоминаний:

```javascript
// Пример функции для Google Apps Script
function sendExpirationReminders() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('users');
  const data = sheet.getDataRange().getValues();
  const today = new Date();
  
  for (let i = 1; i < data.length; i++) {
    const email = data[i][0];
    const expiresAt = new Date(data[i][4]);
    const daysLeft = Math.ceil((expiresAt - today) / (1000 * 60 * 60 * 24));
    
    if (daysLeft === 3) {
      // Отправить email с шаблоном 4
      MailApp.sendEmail({
        to: email,
        subject: '⏰ Напоминание: лицензия скоро истекает!',
        body: '...' // Шаблон 4
      });
    }
  }
}
```
