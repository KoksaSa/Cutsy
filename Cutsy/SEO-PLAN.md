## 🔧 ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### Для деплоя

1. **HTTPS обязателен** (Let's Encrypt бесплатно)
2. **Сжатие Gzip** уже включено в сборке
3. **Кэширование** настроить на уровне nginx/Apache
4. **CDN** для статики (Cloudflare бесплатно)

### nginx конфигурация (пример)

```nginx
server {
    listen 443 ssl http2;
    server_name cutsypro.ru;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    root /var/www/cutsy/dist;
    index index.html;
    
    # Gzip сжатие
    gzip_static on;
    gzip_types text/plain text/css application/json application/javascript;
    
    # Кэширование статики
    location ~* \.(png|jpg|svg|css|js)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
    
    # SPA роутинг
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```
