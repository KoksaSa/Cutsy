# Cutsy CAD PRO — Упаковка в .exe (Electron)

## 📋 Что нужно для создания .exe с иконкой

### 1. Подготовьте иконку

- Формат: `.ico`
- Разрешение: 256×256 (или больше)
- Файл: `electron/icon.ico`

**Где взять иконку:**
- Создайте в графическом редакторе
- Конвертируйте PNG в ICO: https://convertio.co/png-ico/
- Генератор иконок: https://favicon.io/

### 2. Установите зависимости

```bash
cd Cutsy/electron
npm install
```

### 3. Запустите (для теста)

```bash
npm start
```

Проверьте, что приложение работает и показывает вашу иконку.

### 4. Соберите .exe

```bash
npm run build
```

Результат: `electron/release/Cutsy CAD PRO Setup.exe`

---

## 🎯 Альтернатива: простой ярлык без Electron

Если не хотите устанавливать Electron:

1. Создайте ярлык на `dist/index.html`
2. ПКМ → Свойства → Сменить иконку
3. Выберите `.ico` файл

**Минусы:**
- Открывается в браузере (не полноценное .exe)
- Иконка только на ярлыке, не в браузере

---

## ⚠️ Важно

- Electron увеличивает размер программы с 15 MB до ~150 MB
- Для клиентов это не всегда удобно
- **Рекомендация:** продавайте ZIP с `index.html`, а .exe — как опцию за доплату
