# 📋 Настройка формы регистрации через Google Apps Script

## 🎯 Что это даёт

| Преимущество | Описание |
|-------------|----------|
| ✅ Работает из РФ | Без VPN, Google Forms доступен |
| ✅ Email-уведомления | 100 писем/день бесплатно |
| ✅ Авто-выдача ключей | Ключ генерируется автоматически |
| ✅ Красивый интерфейс | Современный UI с анимацией |
| ✅ Нет CORS проблем | Форма работает внутри Apps Script |

## 🔧 Шаг 1: Открой Google Apps Script

1. Открой свою таблицу Google Sheets с лицензиями
2. **Расширения** → **Apps Script**
3. Откроется редактор кода

---

## 🔧 Шаг 2: Вставь код формы

1. Открой файл `google-apps-script-backend-v3.js`
2. Убедись, что функции `doGet()` и `handleFormRegister()` добавлены (они уже есть в коде)

**Проверь, что есть:**

```javascript
// doGet с поддержкой формы
function doGet(e) {
  if (e && e.parameter && e.parameter.action === 'form') {
    return showRegistrationForm();
  }
  return jsonResponse({...});
}

// HTML-форма
function showRegistrationForm() {
  // ... код формы (около 200 строк)
}

// Обработчик регистрации с email
function handleFormRegister(data) {
  // ... код обработки
  MailApp.sendEmail({...});
  return {status: 'ok', ...};
}
```

---

## 🔧 Шаг 3: Разверни как Web App

1. В Apps Script нажми **"Развернуть"** (Deploy) → **"Новое развёртывание"** (New deployment)
2. Нажми на шестерёнку ⚙️ → выбери **"Веб-приложение"** (Web app)
3. Заполни:
   - **Описание:** `Форма регистрации v1`
   - **Кто имеет доступ:** `Все` (Anyone) ⚠️ **ВАЖНО!**
4. Нажми **"Развернуть"** (Deploy)
5. Скопируй **URL веб-приложения** (пример):
   ```
   https://script.google.com/macros/s/AKfycbwII7rNmzt40M2--jBeTJ3mbgrV7H2eXyQ5Xg1ZTTYhYxxisljwNnTdGSKFX3_2J_gkbQ/exec
   ```

---

## 🔧 Шаг 4: Обнови URL в `license-gate.js`

1. Открой `Cutsy/js/license-gate.js`
2. Найди строку (около строки 285):
   ```javascript
   const formUrl = 'https://script.google.com/macros/s/.../exec?action=form';
   ```
3. Замени URL на свой из Шага 3
4. **Важно:** Добавь `?action=form` в конец URL!

**Пример:**
```javascript
const formUrl = 'https://script.google.com/macros/s/ТВОЙ_ID/exec?action=form';
```

## 🔧 Шаг 6: Проверь работу

1. Открой `dist/index.html` в браузере
2. Нажми **"📄 Открыть форму регистрации"**
3. Должна открыться форма в новом окне
4. Заполни тестовые данные:
   - Email: `test@example.com`
   - Пароль: `test123`
   - Тариф: `1 месяц`
5. Нажми **"Зарегистрироваться"**

**Ожидаемый результат:**
- ✅ Появится сообщение "Регистрация успешна!"
- ✅ Покажется лицензионный ключ
- ✅ На `cutsypro@gmail.com` придёт email

## 🔍 Отладка

### Форма не открывается

**Проверь:**
1. URL содержит `?action=form`?
2. Доступ настроен как "Все" (Anyone)?
3. Код сохранён (Ctrl+S)?

### Email не приходит

**Проверь:**
1. Логи в Apps Script (Вид → Логи)
2. Лимит 100 писем/день не превышен?
3. Email `cutsypro@gmail.com` правильный?

### Ошибка "Пользователь уже зарегистрирован"

**Решение:**
- Удали тестового пользователя из таблицы `users`
- Или используй другой email для теста

## ⚠️ Важные замечания

### 1. Лимиты Google

| Лимит | Значение |
|-------|----------|
| Email-уведомления | 100/день (бесплатно) |
| Google Workspace | 1500/день (платно) |
| Execution time | 6 минут на запрос |

### 2. Безопасность

- ✅ Пароль хешируется (SHA-256)
- ✅ Email-уведомление только админу
- ⚠️ Форма не защищена от спама (можно добавить капчу)

### 3. Мобильные устройства

- ✅ Форма адаптирована под мобильные
- ✅ Открывается в новом окне
- ✅ Работает на iOS/Android
