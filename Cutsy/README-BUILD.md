# Cutsy CAD PRO — Сборка для продакшена

## 📋 Что делает сборка

- **Обфускация JS** — затрудняет чтение и модификацию кода
- **Удаление console.log** — очищает код от отладочных сообщений
- **Минификация HTML/CSS** — уменьшает размер файлов
- **Привязка лицензии к устройству** — ключ работает только на том ПК, где активирован

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Генерация лицензионных ключей

```bash
# 1 ключ
npm run generate-key

# 10 ключей
npm run generate-key 10
```

Сохраните ключи в надёжном месте. Каждый ключ одноразовый — привязывается к устройству при первой активации.

### 3. Сборка production-версии

```bash
npm run build
```

Результат появится в папке `dist/`.

### 4. Распространение

Папку `dist/` можно:
- Заархивировать в ZIP и продавать
- Упаковать в Electron-приложение
- Разместить на сайте для скачивания

Клиент открывает `index.html` в браузере, вводит ключ — готово.

## 🔐 Как работает защита

### Привязка к устройству
При активации генерируется **fingerprint** устройства на основе:
- Canvas-отпечатка
- Характеристик экрана
- User-Agent
- Языка и часового пояса

Ключ сохраняется в `localStorage` вместе с fingerprint. При запуске проверяется совпадение — если пользователь скопирует `localStorage` на другой ПК, активация слетит.

### Обфускация
Используется `javascript-obfuscator` с настройками:
- Сжатие и flattening потока управления
- Шифрование строк (base64)
- Hex-имена переменных
- Dead code injection
- Self-defending (попытка форматирования ломает код)

### Удаление логов
`disableConsoleOutput: true` — все `console.log` удаляются или обфусцируются.

## ⚠️ Важно

1. **Полная защита невозможна** — JavaScript в браузере всегда можно декомпилировать. Эта система создаёт барьеры для случайных пользователей.

2. **После сборки не редактируйте `dist/`** — любое изменение сломает self-defending обфускатор.

3. **Сохраняйте исходники** — `dist/` невозможно отредактировать, только пересобрать.

4. **Ключи храните отдельно** — они не восстанавливаются.
