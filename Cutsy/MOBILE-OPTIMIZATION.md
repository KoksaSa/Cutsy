# 📱 Мобильная оптимизация Cutsy CAD PRO

## 🎯 Обзор

Cutsy CAD PRO оптимизирован для работы на мобильных устройствах с сенсорным экраном. Ниже приведена информация о поддерживаемых устройствах, известных ограничениях и рекомендациях по использованию.

---

## ✅ Поддерживаемые устройства и браузеры

### Android
- ✅ **Chrome Mobile** (версия 90+) — полная поддержка
- ✅ **Samsung Internet** (версия 14+) — полная поддержка
- ⚠️ **Firefox Mobile** — ограниченный функционал (touch-события работают нестабильно)
- ⚠️ **Opera Mobile** — может быть медленнее на слабых устройствах

### iOS
- ✅ **Safari** (iOS 13+) — полная поддержка
- ✅ **Chrome for iOS** — работает через Safari engine
- ⚠️ **Firefox for iOS** — работает через Safari engine, возможны ограничения

### Рекомендуемые устройства
- **Смартфоны**: от 5.5" с разрешением 1080p+
- **Планшеты**: от 9.7" с разрешением 1536x2048+
- **Ориентация**: ландшафтная (горизонтальная) рекомендуется

## 🚀 Использование на мобильных устройствах

### Базовые жесты

| Жест | Действие |
|------|----------|
| **Тап** | Выбор объекта / Клик по кнопке |
| **Перетаскивание (1 палец)** | Панорамирование холста / Перемещение объекта |
| **Щипок (2 пальца)** | Зум (приближение/отдаление) |
| **Долгое нажатие** | Контекстное меню (если доступно) |

### Работа с инструментами

1. **Открытие меню инструментов**
   - На мобильных устройствах (< 768px) появляется бургер-меню "☰ Инструменты"
   - Нажмите на кнопку, чтобы развернуть панель инструментов
   - Выберите нужный инструмент тапом

2. **Рисование объектов**
   - Тапните для начала рисования
   - Перетащите для определения размера
   - Тапните ещё раз для завершения

3. **Выбор объектов**
   - Тапните по объекту для выделения
   - Для множественного выбора используйте меню "Выбрать все" или рамку

4. **Перемещение объектов**
   - Нажмите и удерживайте объект
   - Перетащите в нужное место
   - Отпустите для размещения

## ⚠️ Известные ограничения

### Производительность

| Задача | Ограничение | Рекомендация |
|--------|-------------|--------------|
| **Импорт DXF** | Медленный на старых устройствах | Разбивайте большие файлы на части |
| **Раскладка (Nesting)** | 100+ деталей могут занимать время | Используйте фильтр по толщине |
| **Отрисовка** | >5000 объектов может тормозить | Скрывайте неиспользуемые детали |
| **Экспорт PDF** | Может не работать в некоторых браузерах | Используйте экспорт DXF |

### Функциональные ограничения

- ❌ **Импорт DXF с множественным выбором** — на мобильных лучше использовать одиночный импорт
- ❌ **Редактирование точек объектов** — требует высокой точности, рекомендуется на планшетах
- ❌ **Работа с текстом** — ввод текста через виртуальную клавиатуру может быть неудобным
- ⚠️ **Многолистовая раскладка** — в пробном периоде доступен только первый лист

### Браузерные ограничения

| Браузер | Ограничения |
|---------|-------------|
| **Safari iOS** | Ограничения localStorage (6 to 10 MB), может очищать данные при нехватке места |
| **Chrome Android** | Полная поддержка, но на слабых устройствах возможны задержки |
| **Firefox Mobile** | Touch-события работают нестабильно, рекомендуется избегать |

## 🔧 Технические детали

### Touch-события

В проекте реализован файл `js/touch-events.js` с обработчиками:

```javascript
// Основные функции:
- initTouchEvents(canvas) — инициализация touch событий
- getTouchPos(canvas, touch) — преобразование координат
- preventDoubleTapZoom(element) — предотвращение зума по двойному тапу
- preventLongPressMenu(element) — предотвращение long press меню
```

### Адаптивные стили

Мобильная адаптация реализована через CSS медиа-запросы:

```css
/* Планшеты и меньше (до 1024px) */
@media (max-width: 1024px) { ... }

/* Мобильные устройства (до 768px) */
@media (max-width: 768px) { ... }

/* Очень маленькие экраны (до 480px) */
@media (max-width: 480px) { ... }
```

### Мобильное меню

На экранах < 768px:
- Обычная панель инструментов скрывается
- Появляется бургер-меню "☰ Инструменты" в верхней части экрана
- При нажатии открывается раскрывающаяся панель с инструментами

### Touch-оптимизации

- Увеличенные области клика (минимум 44x44px для кнопок)
- Font-size 16px+ для input полей (предотвращает зум на iOS)
- `touch-action: manipulation` для быстрых реакций
- `-webkit-overflow-scrolling: touch` для плавной прокрутки

## 🛠️ Рекомендации для разработчиков

### Добавление touch-поддержки

1. **Создайте обработчики touch событий**:

```javascript
canvas.addEventListener('touchstart', (e) => {
    e.preventDefault();
    const touch = e.touches[0];
    const pos = getTouchPos(canvas, touch);
    // Обработка touch start
}, { passive: false });
```

2. **Эмулируйте mouse события через touch**:

```javascript
function onCanvasTouchStart(x, y, e) {
    // Эмуляция mousedown
    onCanvasMouseDown(x, y, e);
}

function onCanvasTouchMove(x, y, e, isDragging) {
    if (!isDragging) {
        // Эмуляция mousemove
        onCanvasMouseMove(x, y, e);
    }
}

function onCanvasTouchEnd(e, isDragging) {
    if (!isDragging) {
        // Это был тап — можно показать контекстное меню
    }
    // Эмуляция mouseup
    onCanvasMouseUp(e);
}
```

3. **Предотвратите зум и контекстное меню**:

```javascript
// В meta tag
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">

// В CSS
@media (pointer: coarse) {
    a, button, input, select, textarea {
        -webkit-touch-callout: none;
        -webkit-user-select: none;
        user-select: none;
    }
}
```

   - Тестируйте touch-жесты

2. **Реальные устройства**:
   - Подключите через USB
   - Chrome: `chrome://inspect`
   - Safari: Develop → [устройство]

3. **Тестовые сценарии**:

   - ✅ Рисование объектов
   - ✅ Перемещение объектов
   - ✅ Зум и панорамирование
